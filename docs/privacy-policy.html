Privacy Policy

Last updated: 2026-10-24

"Pixel Surgeon Games Listing Refresh" (the "Application") is a private, internal tool built for a single eBay seller — Pixel Surgeon Games (eBay store pixel-surgeon-game-lab) — to automatically refresh that seller's own eBay listings on a weekly schedule. It is not offered to, or used by, the public or by any other eBay sellers or buyers.

What the Application accesses

Using an eBay-issued OAuth authorization from the Pixel Surgeon Games seller account, the Application reads and updates that same seller account's own active eBay listings (titles, descriptions, prices, and listing dates) in order to end older listings and relist them with minor, pre-defined variations.

What the Application does not do

  • It does not collect, process, or store any personal data belonging to eBay buyers, visitors, or any member of the public.
  • It does not share any data with third parties.
  • It is not used by, and does not authenticate, any eBay account other than the Pixel Surgeon Games seller account that authorized it.

Data storage

Listing data (titles, descriptions, prices, and refresh history) used by the Application is stored in a private repository controlled by the seller, solely to operate the Application. No buyer or third-party data is stored.
